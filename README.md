# 期末統計複習網頁

本資料為期末考準備使用，僅供非營利學習用途。

不可商用、販售、轉作付費教材，或用於任何營利服務。

## 檔案說明

- `index.html`：GitHub Pages 入口頁，會自動導向複習網頁。
- `final-review.html`：主要互動複習網頁，包含選擇題、SPSS 操作式實作題、詳解、重置與列印功能。
- `.nojekyll`：讓 GitHub Pages 以靜態檔方式發布。

## 上傳到 GitHub Pages

1. 建立一個新的 GitHub repository。
2. 將本資料夾中的 `index.html`、`final-review.html`、`.nojekyll`、`README.md` 上傳到 repository 根目錄。
3. 到 repository 的 `Settings` > `Pages`。
4. 在 `Build and deployment` 選擇 `Deploy from a branch`。
5. Branch 選 `main`，資料夾選 `/root`，按 `Save`。
6. 等待 GitHub Pages 顯示網址後，即可開啟使用。

## 使用限制

本複習網頁依課堂講義與練習內容整理，僅限期末考準備與自主複習使用。請勿商業使用。
